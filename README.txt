Legacy Studio — Aider dans Docker

Lire README.md pour le démarrage, la configuration, la migration et les limites de sécurité.
Prérequis : Linux, Node.js >= 22.13, npm et Docker local ; Node reste sur l’hôte.
Un appel CLI Aider par demande, sans framework d’agents ni aperçu jouable intégré.
Ne jamais écraser un .env existant ni partager les clés fournisseur.
Les crédits, estimations Aider et paiements Lemon Squeezy sont décrits dans docs/PRICING.md.
